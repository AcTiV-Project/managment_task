# Task Manager — Laravel

A web-based task management application developed with Laravel, designed to allow users to manage their tasks easily and efficiently.

The project implements a user authentication system and a CRUD (Create, Read, Update, Delete) interface for tasks, allowing users to create, view, update, and delete tasks, as well as manage their status and priority.

This project was developed as part of my professional portfolio, with the goal of demonstrating my backend web development skills using Laravel, PHP, and MySQL.

# Characteristics

- User registration and login.
- Authentication system.
- Task creation.
- Task viewing.
- Task editing.
- Task deletion.
- Task status management.
- Priority management.
- Completion date recording.
- Path protection for authenticated users.
- Data validation for forms submitted.
- Data persistence using MySQL.

## Task Status

Each task can be in one of the following statuses:

- Pending
- In Progress
- Completed
- Priorities

## Tasks can be classified according to their priority level:

- Low
- Medium
- High
